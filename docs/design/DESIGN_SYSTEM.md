# bilidown v2 设计系统

> 状态：生效中（change `rebuild-desktop-client` tasks 5.1）
> 定位：遵循 macOS 原生的视觉语言（系统字体、材质、圆角、克制动效），全部界面、图标、文案均为本项目原创实现；强调色 **B 站粉 `#FB7299`**；macOS 优先。
> 依据：`openspec/changes/rebuild-desktop-client/specs/ui-theme/spec.md` 与本项目设计决策 D9/D10/D11。
> 本文档是后续所有 UI 任务的**唯一视觉依据**；与本文不符的实现视为缺陷。

---

## 0. 三条总原则

1. **克制的原生工具感**：面向 macOS 桌面的原生工具，而不是 Web 产品。单一强调色、无渐变按钮、无 hover 位移、阴影只给浮层、发丝线代替重边框。
2. **系统语汇、自有表达**：布局节奏、信息层级、底栏结构与 macOS 系统习惯一致；图标、空态、插画、文案全部为 bilidown 自绘/自写。
3. **可验收**：每个界面必须在明/暗两套主题下按 §8 清单截图评审，未通过不得标记完成。

## 1. 设计原则

| 维度 | 原则 |
| --- | --- |
| 信息架构 | 无顶栏、无侧栏、内容区即队列；单主窗口；辅助内容采用弹窗或独立偏好设置窗口 |
| 底栏 | 底部悬浮全宽胶囊操作条，左/中/右三段；高度 48，按 B 站信息量重排入口 |
| 行卡 | 圆角行卡、左侧 16:9 封面、底部整宽胶囊承载状态与进度；浅色近白卡 + 发丝线，深色 `#1C1C1E` |
| 信息层级 | 标题 + 副信息 + 进度条三层；副信息允许两行：UP 主/来源 · 清晰度 · 编码 · 速度 · 剩余时间 · 条目数 |
| 克制 | 行卡无 hover 抬升/描边；单一强调色；无渐变按钮；hover 只淡入行内操作 |
| 桌面质感 | overlay 标题栏、交通灯留白、系统字体与字号阶梯、独立设置窗口「浮动侧栏 + 表单页」 |
| 偏好设置 | 7 个分类（通用/界面/下载/清晰度与格式/网络/账户/关于），880×600；单色线性图标 + 强调色选中胶囊 |
| 空态 | 居中品牌标识 + 标题 + 引导按钮 + 拖入提示（B 站场景） |
| 动效 | 120–250ms；面板 scale .98→1 + fade；reduced-motion 降级 |
| 图标 | 1.5px stroke、18/20px、系统观感；全部自绘（bill/播放/合集/时钟/齿轮…），禁用系统字体图标充当应用图标 |
| 禁止 | 不使用第三方应用的图标、插画、专属图形、配色或文案 |

**判断标准**：熟悉 macOS 的用户觉得「像系统工具」，同时一眼看出这是 bilidown 的自有品牌。

### 2.4 圆角

窗口 18（Tauri 系统绘制，网页不实现）｜行卡/内容卡 14｜胶囊 999｜sheet 16｜popover/menu 10｜控件 7｜图标方块 8｜缩略图 8｜标签 6。

### 2.5 阴影与描边

- 行卡：**无阴影**，`1px` 发丝线（`--hairline`）或 `0 0 0 1px` 内描边。
- 底栏：发丝线 + `0 1px 2px rgba(0,0,0,.04), 0 8px 24px rgba(0,0,0,.10)`（浅色）/ 深色仅发丝线。
- 面板/菜单/popover：`--shadow-pop: 0 12px 32px rgba(0,0,0,.24), 0 0 0 .5px rgba(0,0,0,.10)`。
- Toast：`0 8px 24px rgba(0,0,0,.18)`。
- 禁止：发光、彩色阴影、多重厚阴影、渐变边框。

### 2.6 动效

| Token | 值 | 用途 |
| --- | --- | --- |
| `--dur-fast` | 120ms | hover/pressed 反馈、图标按钮 |
| `--dur-base` | 180ms | 面板出现/消失、进度条宽度、状态文字 |
| `--dur-slow` | 240ms | 视图切换、列表插入 |
| `--ease-out` | `cubic-bezier(.22,1,.36,1)` | 元素进入 |
| `--ease-in-out` | `cubic-bezier(.4,0,.2,1)` | 状态过渡 |

规则：只动 `transform` / `opacity` / 进度条 `width`；面板 `scale(.98)→1 + fade`；行插入用 `<motion>` 的 `opacity + translateY(4px)`；不做弹簧回弹、不做 hover 位移、不做超过 250ms 的动画；`prefers-reduced-motion` 或设置项关闭时全部降级为即时/纯淡入。

### 2.7 焦点环

```css
:focus-visible { outline: 2px solid var(--accent); outline-offset: 2px; border-radius: 6px; }
```

队列行整卡聚焦：`box-shadow: 0 0 0 2px var(--focus-ring)`（不改变布局）；输入框聚焦：`border-color: var(--accent)` + `box-shadow: 0 0 0 3px var(--accent-weak)`。

### 2.8 图标

- 全部自绘或 MIT/CC0 开源 SVG；**1.5px stroke、round cap/join、18px（底栏/行内）/20px（标题栏/设置分类）**，大图标 24/28。
- 颜色继承 `currentColor`；禁用态 `--text-3` + 40% 不透明度。
- 统一封装 `web/src/components/Icon.tsx`，禁止内联散落 SVG。
- Logo/空态标识为 bilidown 自有：圆角方形 + 向下箭头 + 播放三角的组合，粉色点缀，不使用 macOS 原生视觉 的盾形/箭头 glyph。

## 3. 窗口解剖

```
┌──────────────────────────────────────────────────────────────┐
│ (交通灯留白 80) bilidown            [账户入口]        ← overlay 标题区 40px，data-tauri-drag-region
├──────────────────────────────────────────────────────────────┤
│  ┌ 行卡 ────────────────────────────────────────────┐        │
│  │ [16:9 封面] 标题                          [操作] │        │  ← 内容区：列表/空态
│  │             副信息                            │        │
│  │ [══════ 胶囊进度 ══════ 状态文字 ══════]       │        │
│  └──────────────────────────────────────────────┘        │
│                        ……                                    │
│  ╭──────────────────────────────────────────────────────╮    │
│  │ [+] [剪贴板] [收藏夹]   正在下载 3 项 · 1.2 MB/s  [搜索][清空][历史][帮助] │  ← 悬浮胶囊底栏 48px
│  ╰──────────────────────────────────────────────────────╯    │
└──────────────────────────────────────────────────────────────┘
```

- 交通灯与标题栏由 Tauri 系统绘制；网页只留白（左 80px）并实现 `data-tauri-drag-region` 拖拽区、双击缩放。
- mock/浏览器评审模式下用 CSS 伪交通灯占位（`data-mock="1"` 才渲染，Tauri 内自动隐藏），仅为截图评审，**不是产品 UI**。
- 不设顶栏、侧栏、标签页；历史与队列在同一窗口内切换。
- 窗口尺寸：Tauri 默认 1040×680、最小 760×480；浏览器评审 1440×900@2x。

## 4. 底栏规格

- 悬浮胶囊：左右/底部内缩 16，高 48，圆角 999，`--panel` 底 + 发丝线 + 轻阴影。
- 左段：`添加链接`（主按钮式粉色图标 + 文字，点击弹添加面板）｜`从剪贴板添加`（图标）｜`收藏夹`（图标）。
- 中段：全局状态文案 12px `--text-2`，随队列变化：
  - 空：`没有下载`；进行中：`正在下载 3 项 · 1.2 MB/s`；暂停：`已暂停 2 项`；失败：`1 项失败`；完成：`3 项已完成`；组合最多两段，用 ` · ` 连接。
- 右段：`搜索`（历史视图内聚焦搜索框；队列视图过滤当前列表）｜`清空`（已完成）｜`历史`（切换视图）｜`帮助`（菜单：快捷键/日志/GitHub）。
- 全部图标按钮 28×28、tooltip 200ms 延迟、hover `--hover-fill`、按下 `--pressed-fill`、激活态（历史视图打开）用 `--accent` + `--accent-weak` 底。
- 大列表（>20 项，虚拟滚动）时中段状态前加 `共 N 项 · `，避免「统计数字 ≠ 可见行数」被误读。
- 底栏不遮挡内容：列表 `padding-bottom: calc(var(--bottombar-h) + 32px)`。

## 5. 队列行卡规格

- 尺寸：高 104（内容自适应 96–116），宽 = 内容区宽，间距 8，圆角 14，`--card` 底 + `0 0 0 1px var(--hairline)`。
- 内部栅格：左封面 144×81（16:9，圆角 8，失败态叠 40% 暗层 + 状态圆标）；右侧 `padding: 10px 12px 10px 12px`：
  - 标题 13/600 单行省略；副信息 11/400 `--text-2` 单行，格式：`UP 主 · 来源类型 · 清晰度/编码`（第二行仅在宽 ≥ 560 时出现：速度 · 剩余 · 已下载/总量）。
  - 右上角：hover 淡入的行内操作（暂停/继续、在 Finder 显示、更多菜单），默认不可见但保留布局空间；`focus-within` 时可见。
  - 底部：胶囊进度条 `--progress-h:24`，左右内缩 6，距底 6，轨道 `--accent-weak`，填充 `--accent`（下载中）/`--success`（完成）/`--danger`（失败）/`--text-3`（暂停、取消、排队）；左端状态图标 14px，居中状态文字 12px（下载中显示 `45% · 12.4 / 27.8 MB`，完成显示 `下载完成 · 27.8 MB`，失败显示可读原因，暂停显示 `已暂停 · 继续`）。
- 9 种状态与视觉：

| # | 状态 | 进度填充 | 状态图标 | 文案示例 | 行内操作 |
| --- | --- | --- | --- | --- | --- |
| 1 | queued 排队中 | `--text-3` 8% | 时钟 | `排队中` | 暂停、移除 |
| 2 | resolving 解析中 | 不确定条纹/animated | 旋转 | `解析中…` | 取消 |
| 3 | downloading 下载中 | `--accent` + 百分比 | 下载箭头 | `45% · 12.4 / 27.8 MB` | 暂停、取消 |
| 4 | merging 合并中 | `--accent` 90% + 不确定 | 齿轮旋转 | `合并中…` | 取消 |
| 5 | paused 已暂停 | `--text-3` 保持百分比 | 暂停 | `已暂停 · 45%` | 继续、取消 |
| 6 | completed 完成 | `--success` | 对勾 | `下载完成 · 27.8 MB` | Finder、打开、更多 |
| 7 | failed 失败 | `--danger` | 感叹号 | `登录已失效，请重新扫码` | 重试、详情、移除 |
| 8 | cancelled 已取消 | `--text-3` | 禁止 | `已取消` | 重试、移除 |
| 9 | restored 恢复中 | `--warning` 24% | 恢复箭头 | `已从上次退出恢复，点继续` | 继续、移除 |

- 标题行右侧常显一条次要信息（下载中＝剩余时间、合并中＝百分比、暂停＝已下载/总量、完成＝文件大小、失败＝失败于百分比），hover/focus 时交叉淡出为行内操作按钮（暂停/继续/重试/Finder/更多），不改变布局、不加描边。
- 交互克制：行卡 hover **不改变底色/不抬升/不描边**；仅淡入行内操作按钮（120ms）。点击非按钮区域打开任务详情；右键菜单打开时标题区显示 `--hover-fill` 底板。
- 键盘：方向键移动焦点（`tabIndex` 管理），Enter 打开详情，Space 暂停/继续，Delete 移除（带确认），右键菜单 Shift+F10。
- 缩略图：封面失败显示自有占位（品牌色浅底 + 图标）；加载中骨架 120ms 淡入。
- 行卡与列表：虚拟滚动（`@tanstack/react-virtual`），`overscroll-behavior: contain`，滚动条隐藏（overlay），滚动时底栏保持悬浮。

## 6. 逐屏规格

### 6.1 主窗口 · 空态
- 内容区居中：品牌标识 96×96（圆角 22，粉色 8% 底 + 粉色箭头/播放组合）、标题 15/600「拖入或粘贴 B 站链接」、副标题 12/`--text-2`「支持视频 · 番剧 · 音频 · 专栏，粘贴后自动解析」、主按钮「添加链接」、下方提示 11/`--text-3`「也可以按 ⌘O 打开链接面板」。
- 底栏保持完整可用，状态文字 `没有下载`。
- 不允许出现表格线、空白列表骨架或过期文案。

### 6.2 主窗口 · 队列（含混合状态）
- 行卡列表，间距 8，顶部距标题栏 4，左右 16。
- 列表顶部不设列头/分组标题；滚动条隐藏。
- 15+ 行时虚拟滚动；滚动到顶部/底部不回弹（`overscroll-behavior: contain`）。

### 6.3 历史视图

## 10. 实现约束（硬规则）

1. 只用系统字体与系统字号，无 webfont；图标自绘/开源 SVG，禁止 macOS 原生视觉 素材。
2. 自绘 overlay 标题栏 + `data-tauri-drag-region`；交通灯留白精确（左 80px）；mock 模式才渲染伪交通灯。
3. 滚动条 overlay 化并隐藏；队列/历史必须虚拟滚动；只对 transform/opacity 动画。
4. 无 Web 审美残留：渐变按钮、hover 位移、发光、重阴影、圆角混用、模糊卡片。
5. 表单控件全部自绘，对齐系统偏好设置；不允许裸 `<input>`/`<select>` 的浏览器外观。
6. 所有用户可见文案集中 `web/src/i18n/zh-CN.ts`；所有颜色/时长引用 token。
7. 与本文档偏离必须先改本文档并通知 Lead；不得"实现时顺便决定"。
8. 品牌资产（logo/应用图标/空态标识）与 Tauri 图标生成命令见 `docs/design/BRAND.md`。
9. **未接线操作策略**：mock 模式全部可用（视觉验收）；真实 adapter 下尚未接线的操作（重新下载、复制链接、Finder 显示、打开文件、复制诊断、收藏夹）禁用并提示「待接线」，不得点击无反应；shell 落地后移除 `web/src/lib/capabilities.ts` 对应项。
10. **偏好设置控件策略**：设置页只出现真正读写 shell `Settings` 的控件；未接线的项不出现（登录时启动、播放提示音、历史保留策略已移除）；core 固有行为（退出保留未完成队列）用静态说明行呈现，不做假开关。
11. **收藏夹面板（FavoritesPanel）**：入口、面板标题、空态/toast 统一使用「bilibili收藏夹」；Sheet 内为「头部固定 + 内容区 `flex-1 min-h-0 overflow-y-auto`」，长列表（mock 15 个收藏夹）与 760×480 窄窗均可滚动，空态/骨架不撑破。
12. **磨砂玻璃背景（实验性，默认关闭）**：`data-glass="on"` 时窗口根容器与浮层使用半透明 token + `backdrop-filter`，设置项位于 界面 → 磨砂玻璃背景（localStorage 持久化）。真实 Tauri 2（WKWebView）下 `windowEffects: underWindowBackground` 实测未将桌面材质透传到 web 内容（半透明层与 WebView 白底混合，暗色被提亮成灰），故默认关闭并保留开关；后续若 Shell 换用 `hudWindow` / `fullScreenUI` 生效，再复测并调整 alpha（详见 `.agents/qa/vibrancy/README.md`）。
