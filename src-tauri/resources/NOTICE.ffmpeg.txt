bilidown 内置 ffmpeg（LGPL）说明
================================

本安装包内含 ffmpeg 可执行文件（sidecar），用于 DASH 音视频合并与 MP3 转码。

Windows x64
-----------

来源：https://github.com/BtbN/FFmpeg-Builds
构建：ffmpeg-master-latest-win64-lgpl.zip（LGPL 构建，Windows x64）
获取与校验：仓库内 `scripts/fetch-ffmpeg.mjs` 按 `scripts/ffmpeg.lock.json` 固定的
URL 与 SHA256 下载并解包，本地与 CI 使用同一二进制；二进制本身不入库。

许可：该 ffmpeg 构建以 GNU Lesser General Public License v3（LGPLv3）发布，
随包附带完整许可文本 `COPYING.LGPLv3.ffmpeg`。ffmpeg 源码可从
https://ffmpeg.org/download.html 或 https://github.com/FFmpeg/FFmpeg 获取；
BtbN 构建脚本见 https://github.com/BtbN/FFmpeg-Builds。

macOS 13+ Apple Silicon
-----------------------

构建：FFmpeg 8.1.3 + LAME 3.100，原生 arm64 静态 sidecar。
获取与校验：`scripts/ffmpeg.lock.json` 固定官方 FFmpeg 源码和 LAME 源码的 URL、
文件大小与 SHA256；`scripts/build-ffmpeg-macos.sh` 校验后构建，本地与 CI 使用同一
配置。二进制本身不入库。

许可：FFmpeg 以 LGPL v2.1 or later 发布，LAME 以 GNU Library General Public
License v2 发布。随包附带 `COPYING.LGPLv2.1.ffmpeg`、`COPYING.LAME` 与
`FFMPEG-SOURCE.txt`。构建未启用 GPL、non-free 或 LGPLv3-only 组件。

源码与复现信息见 `FFMPEG-SOURCE.txt`。完整构建脚本位于 bilidown 仓库的
`scripts/build-ffmpeg-macos.sh`，可在 Apple Silicon Mac 上重新生成同一配置。

本应用仅调用 ffmpeg 的可执行文件进行本地转码/合并，不对其进行修改。
